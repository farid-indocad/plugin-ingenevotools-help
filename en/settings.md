# Settings

This page explains all options available in the plugin settings dialog. Open settings using the `IVO:SETTINGS` command.

## General

| Option | Description |
|:-------|:------------|
| **Help URL** | Online documentation URL opened by the `IVO:HELP` command. Default: `https://farid-indocad.github.io/plugin-ingenevotools-help/` |

## Structure

### Column

Default column type settings used by `IVO:FRAMING` and `IVO:COLUMN` commands.

| Option | Description |
|:-------|:------------|
| **Column Type** | Column section/type to draw (e.g., H-Beam, Pipe, Box) |

### Bracing

Default bracing type settings used by `IVO:BRACING` command.

| Option | Description |
|:-------|:------------|
| **Bracing Type** | Bracing type/section to draw |

> [!NOTE]
