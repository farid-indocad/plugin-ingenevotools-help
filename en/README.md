# IngenevoTools

> A BricsCAD plugin for drafting & engineering productivity.

---

## Welcome 👋

**IngenevoTools** is a BricsCAD plugin that speeds up drafting and engineering work — from drawing structure and building sheets out of ViewFrames, to filling title blocks in bulk from Excel and printing the lot to PDF.

Available for **BricsCAD V20 through V26**.

## Quick Start

1. **[Installation](en/installation.md)** — four steps, no Administrator rights
2. **[Getting Started](en/getting-started.md)** — one drawing from start to print
3. **[Command List](en/command-list.md)** — every command, grouped by panel

## What's inside

Commands are grouped exactly as the panels are on the **Ingenevo Tools** ribbon tab:

| Panel | What it covers |
|:------|:---------------|
| **Print** | Batch print layouts to PDF, as one combined file or one per sheet |
| **Sheet Manager** | Build layouts from ViewFrame blocks, manage the Excel register, fill title blocks in bulk, sort and renumber sheets |
| **Utilities** | Safe explode, SOLID to hatch, block replacement, advanced selection, and layout setting unification |
| **Structure** | Framing, columns, beams, bracing, footings, boundaries, and member schedules |
| **Civil** | Pipe outlet elevation calculation |
| **Detail Library** | A palette of standard detail drawings |
| **Settings** | Profile-based plugin configuration |
| **Help** | Licensing, documentation, and version information |

## Navigation

Use the **sidebar on the left** to browse by ribbon panel, or **🔍 Search** above it to find a specific command.
