# IngenevoTools

> BricsCAD plugin for drafting & engineering productivity.

---

## Welcome 👋

**IngenevoTools** is a modular BricsCAD plugin that provides **36 commands** to speed up your drafting and engineering workflow. The plugin is available for BricsCAD V20 through V26.

## Key Features

- 🏗️ **Structural Tools** — Framing, Column, Beam, and Bracing for steel structure drawings
- 🔄 **Block Management** — Replace Block, Change Base Point, and Safe Explode
- 📐 **Layout Management** — Sort Layout, Renumber Layout, Match All Layout Settings
- 📄 **Plot & Export** — Batch Print PDF for printing all layouts at once
- 📚 **Detail Library** — Standard detail drawing library palette
- 🔧 **Utility Tools** — Selection tools, Solid2Hatch, Title Block updater, and more
