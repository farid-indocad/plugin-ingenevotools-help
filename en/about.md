# About IngenevoTools

## Overview

**IngenevoTools** is a modular BricsCAD plugin designed for enhanced drafting and structural engineering efficiency, delivering 36 dedicated commands.

## Compatibility

| BricsCAD Version | Status |
|:-----------------|:-------|
| V20 – V21 | ✅ Supported (.NET Framework 4.6.1) |
| V22 – V25 | ✅ Supported (.NET Framework 4.8) |
| V26 | ✅ Supported (.NET 8.0) |
