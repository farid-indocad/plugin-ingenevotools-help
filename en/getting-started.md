# Getting Started

Guide to start using IngenevoTools after installation.

## Step 1: Load the Plugin

Follow one of the methods on the [Installation](en/installation.md) page to load the plugin into BricsCAD.

## Step 2: Explore the Ribbon Panel

After loading the plugin, the **Ingenevo Tools** tab will appear in the BricsCAD Ribbon. This tab contains 14 panels grouping commands by function.

<!-- screenshot -->

## Step 3: Run Your First Command

Try running your first command:

1. Type `IVO:COMMANDS` in the command line
2. See the list of all available commands
3. Try typing `IVO:ABOUT` to see plugin info

## Step 4: Configure Settings

Open plugin settings with `IVO:SETTINGS` to customize:

- **General** — Help URL, general preferences
- **Structure > Column** — Default column type for Framing commands
- **Structure > Bracing** — Default bracing type

See the [Settings](en/settings.md) page for full details.

## Tips

> [!TIP]
> All IngenevoTools commands use the `IVO:` prefix. Type `IVO:` in the command line and use BricsCAD autocomplete to find commands.
