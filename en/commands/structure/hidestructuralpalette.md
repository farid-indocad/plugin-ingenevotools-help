# IVO:HIDESTRUCTURALPALETTE

> Hides the Structural palette.

## How to Access

- **Ribbon:** — (no ribbon button)
- **Command Line:** `IVO:HIDESTRUCTURALPALETTE`
- **Alias:** —

## How to Use

1. Run `IVO:HIDESTRUCTURALPALETTE`
2. The Structural palette is hidden if it was showing
3. If it is already hidden, the command does nothing

<!-- screenshot -->

## Tips & Notes

> [!NOTE]
> This command **still runs without an active license** — the only one outside the Help and Settings commands that does, and deliberately so: refusing it over a licence would only trap you with a palette you cannot close.

> [!TIP]
> Useful in scripts and toolbars where a toggle would be ambiguous — this command only ever ends with the palette hidden.
