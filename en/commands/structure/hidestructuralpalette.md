# IVO:HIDESTRUCTURALPALETTE

> Menyembunyikan palette Structural.

## How to Access

- **Ribbon:** Ingenevo Tools Tab → Panel Structural Palette
- **Command Line:** `IVO:HIDESTRUCTURALPALETTE`
- **Alias:** —

## How to Use

1. Jalankan perintah `IVO:HIDESTRUCTURALPALETTE`
2. Palette Structural akan disembunyikan jika sedang ditampilkan
3. Jika palette sudah tersembunyi, perintah ini tidak melakukan apa-apa
