# IVO:SHOWSTRUCTURALPALETTE

> Shows the Structural palette.

## How to Access

- **Ribbon:** — (no ribbon button)
- **Command Line:** `IVO:SHOWSTRUCTURALPALETTE`
- **Alias:** —

## How to Use

1. Run `IVO:SHOWSTRUCTURALPALETTE`
2. The Structural palette is shown if it was hidden
3. If it is already showing, the command does nothing

<!-- screenshot -->

## Tips & Notes

> [!WARNING]
> This command requires an **active license**. Run [IVO:LICENSE](en/commands/help/license.md) to activate yours.

> [!TIP]
> Useful in scripts and toolbars where a toggle would be ambiguous — this command only ever ends with the palette visible.
