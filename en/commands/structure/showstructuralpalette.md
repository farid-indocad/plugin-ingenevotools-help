# IVO:SHOWSTRUCTURALPALETTE

> Menampilkan palette Structural.

## How to Access

- **Ribbon:** Ingenevo Tools Tab → Panel Structural Palette
- **Command Line:** `IVO:SHOWSTRUCTURALPALETTE`
- **Alias:** —

## How to Use

1. Jalankan perintah `IVO:SHOWSTRUCTURALPALETTE`
2. Palette Structural akan ditampilkan jika sedang tersembunyi
3. Jika palette sudah ditampilkan, perintah ini tidak melakukan apa-apa
