# IVO:COLUMN

> Draws a column at every picked vertex, without beams.

## How to Access

- **Ribbon:** Ingenevo Tools Tab → Structure Panel → Column button
- **Command Line:** `IVO:COLUMN`
- **Alias:** —

## How to Use

1. Run `IVO:COLUMN`
2. Click a point to place a column there
3. Keep clicking to place more columns
4. Press **Enter** or **right-click** to finish

## Tips & Notes

> [!WARNING]
> This command requires an **active license**. Run [IVO:LICENSE](en/commands/help/license.md) to activate yours.

> [!TIP]
> The column type comes from the Structural palette's **Framing** tab, and can also be set under `IVO:SETTINGS` → **Structure > Column**.

> [!TIP]
> To draw columns and beams in one pass, use [IVO:FRAMING](en/commands/structure/framing.md). To place columns on beams that already exist, use [IVO:GENCOLUMN](en/commands/structure/gencolumn.md).

## See Also

- [IVO:FRAMING](en/commands/structure/framing.md) — columns and beams in one chain
- [IVO:GENCOLUMN](en/commands/structure/gencolumn.md) — columns at the ends of existing beams
- [IVO:BEAM](en/commands/structure/beam.md) — beams only
