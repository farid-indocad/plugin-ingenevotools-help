# IVO:COLUMN

> Menggambar column saja di setiap vertex yang dipick, tanpa beam.

## How to Access

- **Ribbon:** Ingenevo Tools Tab → Panel Framing → Button Column
- **Command Line:** `IVO:COLUMN`
- **Alias:** —

## How to Use

1. Jalankan perintah `IVO:COLUMN`
2. Klik titik di mana column akan ditempatkan
3. Lanjutkan mengklik titik-titik lain untuk menempatkan column tambahan
4. Tekan **Enter** atau **klik kanan** untuk mengakhiri perintah

<!-- screenshot -->

## Tips & Notes

> [!TIP]
> Tipe column dapat diatur melalui `IVO:SETTINGS` → **Structure > Column**.

> [!TIP]
> Untuk menggambar column + beam sekaligus, gunakan [IVO:FRAMING](commands/structure/framing.md).
