# IVO:ABOUT

> Membuka dialog berisi informasi pembuat, versi plugin, dan hak cipta.

## How to Access

- **Ribbon:** Ingenevo Tools Tab → Panel Utility → Button About
- **Command Line:** `IVO:ABOUT`
- **Alias:** —

## How to Use

1. Jalankan perintah `IVO:ABOUT`
2. Dialog About akan terbuka menampilkan:
   - Nama plugin dan versi
   - Informasi pembuat
   - Hak cipta
   - Versi BricsCAD yang didukung
