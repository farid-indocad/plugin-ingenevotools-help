# IVO:ABOUT

> Opens a dialog with the plugin's version, author, and copyright information.

## How to Access

- **Ribbon:** Ingenevo Tools Tab → Help Panel → About button
- **Command Line:** `IVO:ABOUT`
- **Alias:** —

## How to Use

1. Run `IVO:ABOUT`
2. The About dialog opens, showing:
   - Plugin name and version
   - Author information
   - Copyright
   - Supported BricsCAD versions

<!-- screenshot -->

## Tips & Notes

> [!NOTE]
> This command runs **without an active license**.

> [!TIP]
> This is the authoritative answer to "which version is actually installed on this machine" — more reliable than any version number written in documentation.
