# IVO:COMMANDS

> Prints the list of every available command on the command line.

## How to Access

- **Ribbon:** — (no ribbon button)
- **Command Line:** `IVO:COMMANDS`
- **Alias:** —

## How to Use

1. Run `IVO:COMMANDS`
2. Every IngenevoTools command is listed on the BricsCAD command line
3. Each command appears with its short description, and its aliases in parentheses

<!-- screenshot -->

## Tips & Notes

> [!NOTE]
> This command runs **without an active license**.

> [!TIP]
> The list is generated from the commands the plugin actually registers, so it cannot fall behind the build you have installed. A command with no description is still printed — marked, not hidden.

> [!TIP]
> For the same list with links, grouped by ribbon panel, see [Command List](en/command-list.md).
