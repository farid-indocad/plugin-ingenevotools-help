# IVO:EDITCREATELAYOUT

> Opens a dialog to edit or create a new layout configuration.

## How to Access

- **Ribbon:** Ingenevo Tools Tab → Panel Sheet Manager → Button Edit Create Layout
- **Command Line:** `IVO:EDITCREATELAYOUT`
- **Alias:** —

## How to Use

1. Run the command `IVO:EDITCREATELAYOUT`
2. The layout configuration dialog will appear
3. Edit existing layout settings or create a new layout configuration
4. Save changes to apply the configuration

## Tips & Notes

> [!WARNING]
> This command requires an **active license**. Run [IVO:LICENSE](/en/commands/help/license.md) to activate your license.

> [!TIP]
> Use this command to prepare layout templates before adding new layouts with [IVO:ADDLAYOUT](/en/commands/sheet-manager/addlayout.md).
