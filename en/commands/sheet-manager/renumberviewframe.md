# IVO:RENUMBERVIEWFRAME

> Renumbers viewframe (viewport frame) labels in layouts.

## How to Access

- **Ribbon:** Ingenevo Tools Tab → Panel Sheet Manager → Button Renumber Viewframe
- **Command Line:** `IVO:RENUMBERVIEWFRAME`
- **Alias:** —

## How to Use

1. Run the command `IVO:RENUMBERVIEWFRAME`
2. Select the viewframes to renumber or select all
3. Specify the desired numbering format
4. Viewframes will be renumbered according to the settings

## Tips & Notes

> [!WARNING]
> This command requires an **active license**. Run [IVO:LICENSE](/en/commands/help/license.md) to activate your license.

> [!TIP]
> Use this command after adding or removing viewframes to maintain consistent numbering. Works well alongside [IVO:RENUMBERLAYOUT](/en/commands/sheet-manager/renumberlayout.md).
