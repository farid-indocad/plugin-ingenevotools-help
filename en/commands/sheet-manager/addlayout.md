# IVO:ADDLAYOUT

> Adds new layout tabs to the active drawing document.

## How to Access

- **Ribbon:** Ingenevo Tools Tab → Panel Sheet Manager → Button Add Layout
- **Command Line:** `IVO:ADDLAYOUT`
- **Alias:** —

## How to Use

1. Run the command `IVO:ADDLAYOUT`
2. Specify the number and configuration of layouts to add
3. New layouts will be added to the drawing document

<!-- screenshot -->

## Tips & Notes

> [!WARNING]
> This command requires an **active license**. Run [IVO:LICENSE](/en/commands/help/license.md) to activate your license.

> [!TIP]
> After adding layouts, use [IVO:SORTLAYOUT](/en/commands/sheet-manager/sortlayout.md) to reorder layout tabs and [IVO:RENUMBERLAYOUT](/en/commands/sheet-manager/renumberlayout.md) to fix numbering.
