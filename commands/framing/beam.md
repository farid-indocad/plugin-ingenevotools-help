# IVO:BEAM

> Menggambar garis beam berlabel saja di setiap segmen chain yang dipick, tanpa column.

## Cara Akses

- **Ribbon:** Tab Ingenevo Tools → Panel Framing → Tombol Beam
- **Command Line:** `IVO:BEAM`
- **Alias:** —

## Cara Penggunaan

1. Jalankan perintah `IVO:BEAM`
2. Klik titik awal segmen beam
3. Klik titik akhir segmen beam — garis beam berlabel akan digambar
4. Lanjutkan mengklik titik-titik berikutnya untuk segmen beam tambahan
5. Tekan **Enter** atau **klik kanan** untuk mengakhiri perintah

## Tips & Catatan

> [!TIP]
> Untuk menggambar beam + column sekaligus, gunakan [IVO:FRAMING](commands/framing/framing.md).
