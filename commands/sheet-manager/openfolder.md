# IVO:OPENFOLDER

> Membuka folder lokasi file gambar yang sedang aktif di Windows Explorer.

## Cara Akses

- **Ribbon:** Tab Ingenevo Tools → Panel Sheet Manager → Tombol Open Folder
- **Command Line:** `IVO:OPENFOLDER`
- **Alias:** —

## Cara Penggunaan

1. Pastikan dokumen gambar aktif sudah tersimpan
2. Jalankan perintah `IVO:OPENFOLDER`
3. Windows Explorer akan terbuka pada folder tempat file gambar aktif berada

<!-- screenshot -->

## Tips & Catatan

> [!TIP]
> Perintah ini berguna untuk cepat mengakses folder proyek tanpa harus mencari secara manual di Windows Explorer.

> [!NOTE]
> Jika dokumen belum pernah disimpan, perintah ini mungkin tidak dapat menentukan lokasi folder.
