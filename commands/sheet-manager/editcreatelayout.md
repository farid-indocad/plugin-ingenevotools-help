# IVO:EDITCREATELAYOUT

> Membuka dialog untuk mengedit atau membuat konfigurasi layout baru.

## Cara Akses

- **Ribbon:** Tab Ingenevo Tools → Panel Sheet Manager → Tombol Edit Create Layout
- **Command Line:** `IVO:EDITCREATELAYOUT`
- **Alias:** —

## Cara Penggunaan

1. Jalankan perintah `IVO:EDITCREATELAYOUT`
2. Dialog konfigurasi layout akan muncul
3. Edit pengaturan layout yang sudah ada atau buat konfigurasi layout baru
4. Simpan perubahan untuk menerapkan konfigurasi

<!-- screenshot -->

## Tips & Catatan

> [!WARNING]
> Perintah ini membutuhkan **lisensi aktif**. Jalankan [IVO:LICENSE](commands/help/license.md) untuk mengaktifkan lisensi.

> [!TIP]
> Gunakan perintah ini untuk menyiapkan template layout sebelum menambahkan layout baru dengan [IVO:ADDLAYOUT](commands/sheet-manager/addlayout.md).
