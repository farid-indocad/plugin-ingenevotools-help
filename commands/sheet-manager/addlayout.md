# IVO:ADDLAYOUT

> Menambahkan layout tab baru ke dokumen gambar yang aktif.

## Cara Akses

- **Ribbon:** Tab Ingenevo Tools → Panel Sheet Manager → Tombol Add Layout
- **Command Line:** `IVO:ADDLAYOUT`
- **Alias:** —

## Cara Penggunaan

1. Jalankan perintah `IVO:ADDLAYOUT`
2. Tentukan jumlah dan konfigurasi layout yang ingin ditambahkan
3. Layout baru akan ditambahkan ke dokumen gambar

<!-- screenshot -->

## Tips & Catatan

> [!WARNING]
> Perintah ini membutuhkan **lisensi aktif**. Jalankan [IVO:LICENSE](commands/help/license.md) untuk mengaktifkan lisensi.

> [!TIP]
> Setelah menambahkan layout, gunakan [IVO:SORTLAYOUT](commands/sheet-manager/sortlayout.md) untuk mengurutkan ulang layout tabs dan [IVO:RENUMBERLAYOUT](commands/sheet-manager/renumberlayout.md) untuk memperbaiki penomoran.
