# IVO:SORTLAYOUT

> Mengurutkan layout tabs secara numerik atau alfabetis.

## Cara Akses

- **Ribbon:** Tab Ingenevo Tools → Panel Layout → Tombol Sort Layout
- **Command Line:** `IVO:SORTLAYOUT`
- **Alias:** —

## Cara Penggunaan

1. Jalankan perintah `IVO:SORTLAYOUT`
2. Pilih metode pengurutan (numerik atau alfabetis)
3. Semua layout tabs akan diurutkan ulang sesuai metode yang dipilih

<!-- screenshot -->

## Tips & Catatan

> [!TIP]
> Perintah ini berguna untuk menata ulang layout tabs yang berantakan setelah banyak perubahan. Layout "Model" tidak ikut diurutkan.
