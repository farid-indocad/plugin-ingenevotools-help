# IVO:DETAILLIBRARYSETTINGS

> Mengatur folder library, folder cache thumbnail, dan opsi refresh Detail Library lewat command line.

## Cara Akses

- **Ribbon:** — (tidak ada tombol ribbon)
- **Command Line:** `IVO:DETAILLIBRARYSETTINGS`
- **Alias:** —

## Cara Penggunaan

1. Jalankan perintah `IVO:DETAILLIBRARYSETTINGS`
2. Ikuti prompt di command line untuk mengatur:
   - Folder library (lokasi file gambar detail)
   - Folder cache thumbnail (lokasi penyimpanan preview)
   - Opsi refresh cache

## Opsi / Parameter

| Parameter | Deskripsi |
|:----------|:----------|
| **Library Folder** | Path folder yang berisi file gambar detail standar |
| **Cache Folder** | Path folder untuk menyimpan thumbnail preview |
| **Refresh** | Opsi untuk memperbarui cache thumbnail |
