# IVO:COMMANDS

> Menampilkan daftar seluruh perintah yang tersedia di command line.

## Cara Akses

- **Ribbon:** Tab Ingenevo Tools → Panel Utility → Tombol Commands
- **Command Line:** `IVO:COMMANDS`
- **Alias:** —

## Cara Penggunaan

1. Jalankan perintah `IVO:COMMANDS`
2. Daftar seluruh perintah IngenevoTools akan ditampilkan di command line BricsCAD
3. Setiap perintah ditampilkan dengan deskripsi singkatnya

<!-- screenshot -->

## Tips & Catatan

> [!TIP]
> Perintah ini berguna untuk melihat referensi cepat semua perintah yang tersedia langsung di dalam BricsCAD tanpa membuka browser.
