# IVO:LICENSE

> Membuka dialog modal aktivasi/manajemen lisensi.

## Cara Akses

- **Ribbon:** Tab Ingenevo Tools → Panel License → Tombol License
- **Command Line:** `IVO:LICENSE`
- **Alias:** —

## Cara Penggunaan

1. Jalankan perintah `IVO:LICENSE`
2. Dialog manajemen lisensi akan terbuka
3. Masukkan kode lisensi untuk aktivasi
4. Atau kelola lisensi yang sudah ada (lihat status, perpanjang, dll.)

<!-- screenshot -->

## Tips & Catatan

> [!NOTE]
> Beberapa fitur plugin memerlukan lisensi aktif. Gunakan [IVO:LICENSEINFO](commands/license/licenseinfo.md) untuk mengecek status lisensi tanpa membuka dialog.
