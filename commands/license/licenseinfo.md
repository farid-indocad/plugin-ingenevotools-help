# IVO:LICENSEINFO

> Menampilkan status dan tipe lisensi aktif saat ini pada command line.

## Cara Akses

- **Ribbon:** Tab Ingenevo Tools → Panel License
- **Command Line:** `IVO:LICENSEINFO`
- **Alias:** —

## Cara Penggunaan

1. Jalankan perintah `IVO:LICENSEINFO`
2. Status lisensi akan ditampilkan di command line BricsCAD, termasuk:
   - Tipe lisensi
   - Status (aktif/expired)
   - Tanggal kedaluwarsa (jika ada)

<!-- screenshot -->

## Tips & Catatan

> [!TIP]
> Perintah ini hanya menampilkan informasi — tidak membuka dialog. Untuk mengelola lisensi, gunakan [IVO:LICENSE](commands/license/license.md).
