# IVO:BLTSCALE

> Mengatur MSLTSCALE (Model Space) dan PSLTSCALE (semua layout) serentak ke 0 atau 1.

## Cara Akses

- **Ribbon:** Tab Ingenevo Tools → Panel Layout → Tombol BLTSCALE
- **Command Line:** `IVO:BLTSCALE`
- **Alias:** `IVO:BLTS`

## Cara Penggunaan

1. Jalankan perintah `IVO:BLTSCALE` atau `IVO:BLTS`
2. Pilih nilai yang diinginkan (0 atau 1)
3. MSLTSCALE dan PSLTSCALE di semua layout akan diatur serentak

## Opsi / Parameter

| Parameter | Deskripsi |
|:----------|:----------|
| **0** | Menonaktifkan linetype scaling berdasarkan annotation scale |
| **1** | Mengaktifkan linetype scaling berdasarkan annotation scale |
