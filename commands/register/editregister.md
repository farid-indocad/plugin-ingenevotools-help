# IVO:EDITREGISTER

> Membuka berkas register metadata Excel yang berasosiasi dengan dokumen gambar yang aktif.

## Cara Akses

- **Ribbon:** Tab Ingenevo Tools → Panel Register → Tombol Edit Register
- **Command Line:** `IVO:EDITREGISTER`
- **Alias:** —

## Cara Penggunaan

1. Pastikan dokumen gambar aktif sudah tersimpan
2. Jalankan perintah `IVO:EDITREGISTER`
3. File register metadata Excel yang terkait akan dibuka di aplikasi spreadsheet default

<!-- screenshot -->

## Tips & Catatan

> [!WARNING]
> Perintah ini membutuhkan **lisensi aktif**. Jalankan [IVO:LICENSE](commands/license/license.md) untuk mengaktifkan lisensi.

> [!NOTE]
> File register Excel harus sudah ada dan berasosiasi dengan dokumen gambar. Lokasi file register ditentukan berdasarkan konvensi penamaan proyek.
