# IVO:BRACING

> Menggambar detail bracing / ikatan angin secara semi-otomatis.

## Cara Akses

- **Ribbon:** Tab Ingenevo Tools → Panel Bracing → Tombol Bracing
- **Command Line:** `IVO:BRACING`
- **Alias:** —

## Cara Penggunaan

1. Jalankan perintah `IVO:BRACING`
2. Ikuti prompt di command line untuk menentukan titik-titik bracing
3. Detail bracing akan digambar secara semi-otomatis berdasarkan tipe yang dipilih

## Opsi / Parameter

Tipe bracing dapat diatur melalui `IVO:SETTINGS` → **Structure > Bracing**.

| Parameter | Deskripsi |
|:----------|:----------|
| **Bracing Type** | Tipe ikatan angin yang akan digambar (diatur di Settings) |

<!-- screenshot -->

## Tips & Catatan

> [!NOTE]
> Pengaturan tipe bracing disimpan di Settings dan akan digunakan sebagai default untuk perintah berikutnya.
