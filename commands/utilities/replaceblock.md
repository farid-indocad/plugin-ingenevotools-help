# IVO:REPLACEBLOCK

> Mengganti instansi block dynamic terpilih dengan block lainnya secara massal.

## Cara Akses

- **Ribbon:** Tab Ingenevo Tools → Panel Block → Tombol Replace Block
- **Command Line:** `IVO:REPLACEBLOCK`
- **Alias:** —

## Cara Penggunaan

1. Jalankan perintah `IVO:REPLACEBLOCK`
2. Pilih block reference yang ingin diganti (source block)
3. Pilih block pengganti (target block)
4. Semua instansi source block dalam gambar akan diganti dengan target block

<!-- screenshot -->

## Tips & Catatan

> [!NOTE]
> Perintah ini bekerja dengan block dynamic. Pastikan block pengganti memiliki atribut yang kompatibel jika diperlukan.
